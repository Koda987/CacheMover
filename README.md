# C 盘腾腾酱 · 缓存搬家 CacheMover

把 C 盘的软件缓存安全迁移到其他盘的可视化工具。原理是 Windows **目录联接（Junction）**：软件以为缓存还在 C 盘原位置，实际数据存在其他盘。**全程不需要管理员权限**。

界面为「C 盘腾腾酱」风格：圆角无边框窗口，动漫少女壁纸作为窗口背景（已嵌入 exe），左侧磨砂半透明导航栏（首页 / 历史记录 / 设置）+ 白色圆角卡片 + 渐变大按钮 + 小猫吉祥物。窗口可用鼠标在任意空白处拖动，右上角为自定义的最小化 / 关闭按钮。所有图标、吉祥物均为程序运行时用 GDI+ 绘制；界面代码在 `CuteUI.cs`（自定义控件库，控件背景真正透明）和 `MainForm.cs`（布局与窗口逻辑）。更换背景图：替换 `assets\bg.jpg` 后重新 `dotnet publish` 即可。

## 程序在哪

免安装版（拷到任何 Windows 10/11 电脑都能直接双击运行）：

```
bin\Release\net8.0-windows\win-x64\publish\CacheMover.exe   （约 64 MB，单文件）
```

## 怎么用

1. 首页点「从常用位置选择 ▾」选一个（如微信聊天记录）自动填入；或直接把文件夹**拖进输入框**。
2. 目标文件夹会自动建议剩余空间最大的盘（如 `D:\CacheLink\xxx`），可修改。
3. 看输入框下方的检查结果：**✘ 必须解决**、⚠ 确认后可继续、✔ 正常。
4. 点「创建软链接」。迁移前**先关闭正在使用该缓存的软件**（微信、浏览器、游戏等）。
5. 迁移完成后先打开软件试用，确认正常，再点「删除备份，释放 C 盘空间」。
6. 「历史记录」页可查看每次迁移的时间、原路径、目标路径、大小和运行日志。

## 安全机制

- **迁移流程**：占用自检（试改名）→ 复制到目标 → 逐字节校验 → 原文件夹改名留备份 → 创建联接 → 校验联接指向。任何一步失败都会自动回滚，原文件夹保持完好。
- **黑名单（直接禁止迁移）**：`C:\Windows`、`Program Files`、用户主目录、`AppData` 三个总目录、`ProgramData` 根目录、`AppData\Local\Microsoft\Windows`（含注册表文件 UsrClass.dat）、`AppData\Local\Packages`（UWP 应用数据）等。
- **警告级（确认后放行）**：`AppData\Local\Microsoft` 其他子目录、OneDrive 云同步目录、临时目录、非 NTFS 目标分区、同分区迁移等。
- **其他检查**：源和目标不能互相嵌套（防止联接指向自己造成死循环）、目标盘剩余空间是否够、目标文件夹必须为空、抽查文件是否被占用。
- **迁移记录**：每次成功迁移追加写入 `%APPDATA%\CacheMover\history.jsonl`，记录原路径、目标路径、备份位置，便于以后排查。

## 注意事项

- 部分软件**大版本更新时可能删除联接、重建真实目录**，迁移会悄悄失效——如果 C 盘空间又涨回来了，检查原位置是不是变成了普通文件夹（迁移记录里有当时的路径）。
- **游戏库**优先用 Steam / Epic 自带的「移动安装库」功能，比联接更稳。
- **OneDrive 等云同步目录**不要用这种方式搬（程序里也会警告）。
- 个别杀毒软件对创建联接会提示，属正常现象。
- 备份删除前一定要先确认对应软件运行正常；备份文件夹（原路径加 `.bak` 后缀）在确认前一直占着 C 盘空间。
